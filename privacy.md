# Privacy Policy — Mikeverse rclone Integration

**Last updated: October 12, 2026**

## Overview

Mikeverse rclone Integration is a personal-use application that allows its owner to access and manage files in their own Google Drive account using rclone.

The application is not offered to the public and has no external users.

## Google Drive Data

The application requests Google Drive access to support file synchronization, backup, retrieval, and management.

Google Drive data is accessed only for operations initiated or authorized by the account owner.

## Data Storage and Sharing

Files remain within the owner's Google Drive account or authorized local storage locations.

OAuth credentials and authorization tokens are stored in the owner's local rclone configuration and are not published on this website.

The application does not sell Google user data, use it for advertising, or intentionally transmit it to unrelated third parties.

## Data Retention and Deletion

The owner controls the files and local configurations used by this integration. Access can be revoked through Google Account security settings, and locally stored authorization credentials can be deleted.
