# Mikeverse rclone Integration

Mikeverse rclone Integration is a private, personal-use utility for connecting the owner's computers to the owner's Google Drive using rclone.

The integration supports personal file synchronization, backup, and document management.

This application is not offered as a public service and does not accept external users.

Google Drive access is authorized directly by the account owner through Google's OAuth authentication process.

No Google account credentials, OAuth tokens, or private Drive documents are published on this website.

For information about data handling, see the [Privacy Policy](privacy).
